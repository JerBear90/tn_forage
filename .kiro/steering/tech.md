# Technical Steering

Use:
- React/Next.js
- TailwindCSS
- Leaflet
- Recharts
- IndexedDB
- Service Worker
- PocketBase
- Stripe
- Redirect-based OAuth SSO

Do not:
- Replace Leaflet
- Break offline functionality
- Require internet for Field Guide/trips/logs
- Store OAuth access tokens in plain localStorage
- Expose secrets in frontend
- Grant membership from frontend
