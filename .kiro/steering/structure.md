# Structure Steering

Keep the repository organized and predictable.

Required:
- Specs in `.kiro/specs/forageflow/`
- Steering in `.kiro/steering/`
- Docs in `/docs`
- Branding in `/public/branding`
- Auth logic in `/src/auth`
- Offline logic in `/src/offline`
- Tests in `/tests`

Do not create duplicate components or placeholder screens and call them complete.
